# Рассылка писем клиентам

Скрипт `mailer.py` отправляет персональные письма списку клиентов с вашей почты через SMTP
(по умолчанию Gmail). Нужен только Python 3.8+, сторонних библиотек нет.

## 1. Пароль приложения Gmail

Обычный пароль Gmail не подойдёт. Сделайте так:
1. Включите двухэтапную аутентификацию: https://myaccount.google.com/security
2. Создайте пароль приложения: https://myaccount.google.com/apppasswords
3. Сохраните 16-значный пароль, он понадобится дальше.

## 2. Настройка

```bash
cd mailer
cp config.example.ini config.ini     # впишите свой адрес и имя отправителя
cp clients.example.csv clients.csv   # ваш список клиентов
```

В `clients.csv` колонка `email` обязательна. Любую другую колонку (`name`, `company`…)
можно подставить в тему и текст письма как `$name`, `${company}`.

Текст письма лежит в `templates/message.txt`, HTML-версия в `templates/message.html`.
Если удалить html-файл, уйдёт только текст.

## 3. Запуск

```bash
export MAILER_PASSWORD="abcd efgh ijkl mnop"   # пароль приложения

python3 mailer.py                         # пробный прогон: покажет письма, ничего не отправит
python3 mailer.py --test you@gmail.com    # одно тестовое письмо себе
python3 mailer.py --send                  # настоящая рассылка
```

Дополнительные параметры:
- `--attach price.pdf photo.jpg`: вложения
- `--subject "Другая тема"`: заменить тему из config.ini
- `--limit 100`: отправить не больше N писем за этот запуск

## Как это работает

- Каждый отправленный адрес записывается в `sent.log`, поэтому при повторном запуске
  письмо никто не получит дважды. Ctrl+C можно нажать в любой момент. Для новой рассылки
  удалите или переименуйте `sent.log`.
- Адреса из `unsubscribed.txt` (один на строку) пропускаются. Добавляйте туда всех, кто попросил отписаться.
- Дубли и некорректные адреса отбрасываются.
- Между письмами пауза `delay_seconds` (по умолчанию 5 секунд).

## Ограничения Gmail

У обычного аккаунта около 500 писем в сутки. Для больших списков запускайте с `--limit`
несколько дней подряд или используйте Google Workspace или сервис рассылок (Unisender,
SendPulse, Mailchimp). Пишите только тем, кто согласился получать письма, иначе Gmail
может заблокировать отправку.

`config.ini`, `clients.csv`, `sent.log` и `unsubscribed.txt` добавлены в `.gitignore`,
пароль и база клиентов в репозиторий не попадут.
